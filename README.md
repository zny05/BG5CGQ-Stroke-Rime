## 二、快速安装（3 步）

### 第 1 步：上传方案文件

用 Hamster 的「文件管理」功能（WiFi 文件管理，浏览器访问 `http://<IP>`），将以下 2 个文件上传到 Rime 目录：

- `stroke_bg5cgq.schema.yaml`
- `stroke_bg5cgq.dict.yaml`

> 或直接把整个文件夹打包成 zip，通过 iOS 分享功能导入仓输入法。

### 第 2 步：上传键盘配置

将 `hamster.yaml` 上传到 Rime 目录（覆盖原有文件）。

### 第 3 步：重新部署 + 切换

1. 在 Hamster 设置中点击「重新部署」（约 1-2 分钟）
2. 在输入法方案列表中选择「BG5CGQ笔画输入」
3. 在键盘设置中切换到自定义键盘「BG5CGQ笔画」
4. 键盘配色选择「9宫格笔画输入」


## 四、编码规则

- **竖钩归竖**：丁=12, 了=52, 小=234
- **提归横**：打=121
- **捺归点**：人=34
- **折**：横折、竖折、弯钩等（竖钩除外）

| 汉字 | 笔顺 | 按键 |
|------|------|------|
| 一 | 横 | 1 |
| 十 | 横竖 | 12 |
| 王 | 横横竖横 | 1121 |
| 中 | 竖横折竖 | 2512 |
| 我 | 撇横竖钩提斜钩撇点 | 3121534 |

**首笔即可选字**：输入第一笔就出现常用字候选，笔画越多候选越精确。
